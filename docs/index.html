DSP / ALGORITHM ARCHITECTURE

Dynamic Sub-Division &
Viterbi Trellis Search

単なるコード置換辞書ではありません。Phase 13で搭載された和声リズム動的分割エンジンは、2拍を超える白玉コードを検出し、直後のターゲットコードのルート音から逆算して裏コード（Tritone Substitution: bII7）やセカンダリードミナント（V7/target）を自動生成して差し込みます。

さらに分割されたパッシングコードを含む全時間ステップをViterbiアルゴリズム（動的計画法）のトレリスへ統合し、曲全体を通して最も声部移動が滑らかなボイシング経路を一瞬で数学的に決定します。

  • [PHASE 13] Harmonic Rhythm Sub-Division & Target Root Back-Calculation
  • [STEP 01] Backtracking & Hard-Limit Pruning (Low Interval Limit)
  • [STEP 02] Static + Transition Voice-Leading Cost Evaluation
  • [STEP 03] Global Optimum Trellis Backtracking across 4 or 8 Bars

// Phase 13: 長いコードブロックを動的に分割し、直後のターゲットへ向かう裏コード(bII7)/V7を逆算挿入
ChordBlock MidiReharmonizerEngine::computeApproachChordForTarget(
    const ChordBlock& sourceBlock, int targetRootPc, double startPpq, double durPpq, bool tritoneSub)
{
    ChordBlock approach = sourceBlock;
    approach.startPpq       = startPpq;
    approach.durationPpq    = durPpq;
    approach.isPassingChord = true;
    // 裏コード (target + 1半音 = bII7) または セカンダリードミナント (target + 7半音 = V7)
    approach.rootPitchClass = normalizePitchClass(targetRootPc + (tritoneSub ? 1 : 7));
    approach.quality        = ChordQuality::Dominant7;
    return approach;
}

// パッシングコードを含む全時間ステップを Viterbi トレリスへ統合して最適ボイシング経路を探索
bool MidiReharmonizerEngine::triggerOfflineReharmonize(bool usePreviewIfEmpty)
{
    progression = subdivideAndInsertPassingChords(progression, profileCopy);
    const auto optimalVoicings = findOptimalVoicingPath(progression, profileCopy);
    reharmonizedSequence_ = renderVoicingPathToMidiEvents(progression, optimalVoicings, profileCopy);
    return true;
}

MUTATION, HARMONIC RHYTHM & ROUTING CONTROLS (左パネル下段)
MUTATION SLIDER (0.0% 〜 100.0%)

和声の過激さと、Phase 13 和声リズム分割（パッシングコード挿入）の密度を同時にコントロールします：

0% 〜 30% (Basic / Safe): 拍の分割は行わず元の和声リズムを維持。テンションや代理コードを抑えたクリーンなDrop2/基本ボイシングを生成。
30% 〜 70% (Advanced / Musical): 9th/11th/13thテンションを解禁。4小節に1〜2箇所の解決ポイント（ツーファイブやターンアラウンド）を自動選別して分割し、裏コード（bII7）やセカンダリードミナントを粋に挿入。
70% 〜 100% (Chaos / Bebop Chain): オルタードテンション（b9, #9, #11, b13）と半音クラスターにボーナスを付与。すべての長い白玉コードを分割し、80%〜100%では1小節を3〜4拍に細分化して「裏コードのさらに裏」まで連鎖挿入。
OPERATING MODE (動作モード)
  • ・Bypass (Thru): 入力されたMIDIとAudioをそのまま後段のシンセへ完全スルーします（D&Dワークフロー時の標準モード）。
  • ・Capture MIDI: DAW再生中に入力されたリアルタイムMIDI演奏を内部バッファへ記録します（スルー出力も維持）。
  • ・Playback Reharm: リハーモナイズ済みのMIDIシーケンスをDAWの再生位置（PPQ）に同期して後段のシンセへ直接送出します。
Groove Sync トグル ＆ Audition (Preview) トグル
  • Groove Sync: サイドチェイン（またはメインAudio入力）のトランジェント（ドラムのアタック）を解析し、環境レイヤーのヒューマナイズよりも優先してノート発音位置をドラムのポケットへ吸着させます。
  • Audition (Preview): 内蔵の12ボイス・ポリフォニック・エレピ音源をONにします。DAW停止中でもプラグイン単体で4小節/8小節のループ試聴が可能です。
SECTION 03

DAWルーティング・ガイド ＆ よくある質問 (FAQ)

Q1. Spire等の外部シンセと一緒に使うには？

完全パススルー設計で共存可能

TriLayerReharmは入力されたオーディオおよびリアルタイムMIDI信号を一切ミュートせず後段へ完全スルーします。
① D&D方式: ピアノロール右上の DRAG MIDI TO DAW からSpire等のトラックへMIDIをドロップ。
② リアルタイム送出: Operating Modeを Playback Reharm にすると、DAW再生に同期して後段へリハーモナイズMIDIを送出します。

Q2. プラグイン単体で音を鳴らせますか？

Audition (Preview) をONにするだけ

左パネル最下段の 「Audition (Preview)」 チェックボックスをONにすると、内蔵のエレピシンセが即座にリハーモナイズ結果を演奏します。
DAWのトランスポートが停止している状態でも、内部クロックによって4小節（または8小節）のコード進行を自動ループ再生するため、プリセット選びやMutationの試行錯誤がプラグイン単体で完結します。

Q3. インストール先とシステム要件は？

Windows 64-bit VST3 標準対応

インストーラー（またはビルドスクリプト）により、WindowsのVST3標準パスへ配置されます：
C:\Program Files\Common Files\VST3\TriLayerReharm.vst3 対応OS: Windows 10 / 11 (64-bit)
