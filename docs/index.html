DSP / ALGORITHM ARCHITECTURE

Dynamic Sub-Division &
Viterbi Trellis Search

単なるコード置換辞書ではありません。和声リズム動的分割エンジンは、2拍を超える白玉コードを検出し、直後のターゲットコードのルート音から逆算して裏コード（Tritone Substitution: bII7）やセカンダリードミナント（V7/target）を自動生成して差し込みます。

さらに分割されたパッシングコードを含む全時間ステップをViterbiアルゴリズム（動的計画法）のトレリスへ統合し、曲全体を通して最も声部移動が滑らかなボイシング経路を一瞬で数学的に決定します。v1.5からは、ここに達人のプレイスタイル（コスト関数）とスケール制約フィルターが統合されています。

Source/Engine/MidiReharmonizerEngine.cpp — C++20
Phase 13 + Viterbi Trellis 
// 長いコードブロックを動的に分割し、直後のターゲットへ向かう裏コード(bII7)/V7を逆算挿入
ChordBlock MidiReharmonizerEngine::computeApproachChordForTarget(
    const ChordBlock& sourceBlock, int targetRootPc, double startPpq, double durPpq, bool tritoneSub)
{
    ChordBlock approach = sourceBlock;
    approach.startPpq       = startPpq;
    approach.durationPpq    = durPpq;
    approach.isPassingChord = true;
    // 裏コード (target + 1半音 = bII7) または セカンダリードミナント (target + 7半音 = V7)
    approach.rootPitchClass = normalizePitchClass(targetRootPc + (tritoneSub ? 1 : 7));
    approach.quality        = ChordQuality::Dominant7;
    return approach;
}

// パッシングコードを含む全時間ステップを Viterbi トレリスへ統合して最適ボイシング経路を探索
bool MidiReharmonizerEngine::triggerOfflineReharmonize(bool usePreviewIfEmpty)
{
    progression = subdivideAndInsertPassingChords(progression, profileCopy);
    const auto optimalVoicings = findOptimalVoicingPath(progression, profileCopy);
    reharmonizedSequence_ = renderVoicingPathToMidiEvents(progression, optimalVoicings, profileCopy);
    return true;
}

SECTION 02

UIコントロール＆パラメーター詳細リファレンス (v1.5)

3-LAYER & PRESET CONTROLS (左パネル上段〜中段)
Layer Safe & Reset ボタン (v1.5)

Layer Safe: ワンクリックで「既存トラックと重ねても濁らない黄金比（Mutation 35%・Neo-Soul）」へ強制スナップします。
Reset: 元のMIDIの構成音（原曲）へ一発で復帰します。Undo (Ctrl+Z) で元に戻せます。

LAYER 1 : GENRE & SCALE (v1.5)

和声理論の骨格（裏コードの有無など）を決定します。v1.5からは Scale Awareness（DorianやMixolydian等）を指定し、アボイドノートを厳格に除外できます。

LAYER 2 : ARTIST (達人シミュレーター / v1.5)

演奏者の「手癖」とボイスリーディング重みを設定します：

  • ・Rootless Master (ex. Bill E.): ルート省略、密集和音(クラスター)、レイドバック
  • ・Quartal Power (ex. McCoy T.): 4度堆積（インターバル5）を選好、力強いベロシティ
  • ・Melody & Bass (ex. Joe P.): Drop2厳守、トップとベースの声部移動を極限まで滑らかに
  • ・Standard: 既存の標準的なバランス
LAYER 3 : ENVIRONMENT (ATMOSPHERE)

音域レンジ（MIDIノート下限・上限）、同時発音声部数（3〜5声）、および低音域の濁りを防ぐ Low Interval Limit を制御します。

MUTATION, ROUTING & LAYERING (左パネル下段)
MUTATION SLIDER (0.0% 〜 100.0%)

和声の過激さと、拍の分割密度（裏コード挿入）をコントロールします。
※v1.5からは「0.0%」の時、重い計算を完全にスキップして原曲をそのまま出力するパススルー（原曲再現）モードとして機能します。

LAYERING TOOLS (v1.5)
  • ・Melody Lock: 元MIDIの最高音(メロディ)を100%固定し、内声のみをViterbiで動かします。
  • ・Pedal Bass: 最初のベース音をフレーズ全体で固定し、上声部だけを動かします（分数コード化）。
MIDI CH. SPLIT & COMPING (v1.5)

最低音(Bass)を「Ch.1」、上声部(Chords)を「Ch.2」に分離して出力。DAWで一瞬でシンセベースとエレピに鳴らし分け可能です。さらに「Neo-Soul Pocket」などのリズム分割（コンピング）を指定できます。

Groove Sync トグル ＆ Audition (Preview) トグル

サイドチェイン入力からのトランジェント吸着（Groove Sync）と、内蔵12ボイス・エレピでの試聴（Audition）を切り替えます。
